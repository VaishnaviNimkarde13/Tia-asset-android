# Nurse Login Scan App

A simple Expo React Native app for nurse login and barcode scanning to mark medication as consumed.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Expo:
   ```bash
   npm start
   ```
3. Run on a device or emulator.

## Features

- Nurse login screen
- Barcode scanning with `expo-barcode-scanner`
- Mark scanned items as consumed
- Recent consumed history list

## Notes

- Default credentials: `nurse` / `1234`
- Camera permission is required for scanning
